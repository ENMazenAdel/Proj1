## 📖 Overview

**Chronos Luxe** is an elegant, modern website designed for a fictional luxury watch brand. The project showcases a visually stunning interface with smooth animations, professional design patterns, and a dark premium aesthetic that reflects the exclusivity of high-end timepieces.

## ✨ Features

- **🎨 Premium Dark Theme** - Sophisticated color palette with gold/blue accents
- **📱 Responsive Design** - Fully optimized for all screen sizes
- **🔍 Interactive Search Bar** - Sleek search functionality in the header
- **📂 Dropdown Navigation** - Multi-level navigation with smooth hover effects
- **🖼️ Hero Section** - Eye-catching full-screen hero with call-to-action buttons
- **💎 Feature Cards** - Animated cards highlighting brand values
- **⏱️ Watch Collections** - Showcase of signature and limited edition timepieces
- **💬 Testimonials** - Client reviews with profile images
- **👤 Founder Section** - About the master horologist
- **📧 Newsletter Signup** - Email subscription form
- **🔗 Social Media Links** - Integrated social media icons

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code recommended)

### Installation

1. **Clone or download** the repository
2. **Open** `index.html` in your browser
3. That's it! No build process required.

```bash
# If using a local server (optional)
# Using VS Code Live Server extension or:
npx serve .
```
